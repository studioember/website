# Studio Ember website

This repository is an Eleventy v4 alpha static site with Nunjucks, Tailwind CSS v4, and vanilla JavaScript. Read `README.md` for the current routes, content ownership, build, and verification commands.

Keep the existing cream, navy, ember, and gold visual language. Planning is a standalone advisory path; implementation is a separate client-owned private-platform path. Do not publish provisional prices, imply that illustrative deliverables are client results, or promise 24/7 support.

Old `pages/` and `posts/` content is intentionally excluded in `.eleventyignore`. Use top-level route folders for published pages. Run `yarn build && yarn test` after changes.
